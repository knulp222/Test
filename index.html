L'outil

Une bibliothèque de prompts qui vous appartient.

Les prompts fournis sont un point de départ, pas un catalogue figé. Tout se renomme, se réorganise et se remplace depuis la page de réglages.

Entièrement personnalisable

Ajoutez vos prompts, choisissez l'emoji et la couleur de chaque secteur, réorganisez les jeux. Un export JSON permet de diffuser la même bibliothèque à toute une équipe.

Simple à utiliser

Un raccourci, un clic. Le prompt est inséré dans le champ actif et copié dans le presse-papiers — s'il reste une case à compléter, elle est surlignée.

Installation

Quatre étapes, deux minutes.

Aucun programme à installer sur l'ordinateur : l'extension est un dossier que Chrome charge.

Téléchargez le fichier ZIP et décompressez-le.

Clic droit → Extraire tout. Gardez le dossier prompt-wheel à un endroit stable, il ne doit pas être supprimé ensuite.

Ouvrez chrome://extensions dans la barre d'adresse.

Sur Edge : edge://extensions

Activez le Mode développeur, en haut à droite.

C'est l'interrupteur qui autorise les extensions chargées depuis un dossier.

Cliquez sur Charger l'extension non empaquetée et choisissez le dossier.

La page de réglages s'ouvre. Rechargez les onglets déjà ouverts, et c'est prêt.

Pourquoi le mode développeur ? Parce que l'extension n'est pas publiée sur le Chrome Web Store. C'est la contrepartie d'un outil qu'on garde chez soi : aucun compte, aucun serveur, aucune donnée envoyée nulle part. Vos prompts restent dans votre navigateur.
